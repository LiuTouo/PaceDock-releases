    常見問題

    怎麼安裝？需要什麼權限？

    需要 Windows 11 x64、WebView2 與管理員權限（GPU 策略操作需要）。安裝版依指示安裝；免安裝版解壓即用。二進位檔未簽署，SmartScreen 警告屬預期行為，可核對 SHA256 校驗檔。

    會不會傷到 GPU 或系統？

    PaceDock 不超頻、不修改頻率、電壓或風扇，只調整 GPU 中斷親和性。套用與還原會重啟顯示裝置，畫面可能短暫閃黑；套用前一定會保存完整策略快照。

    測試結果能保證遊戲變快嗎？

    不能。排名只反映本次合成負載的相對表現；「差異接近」是顯示用啟發式，不是 FPS 改善幅度或統計顯著性。建議以實際遊戲體驗做最終判斷。

    跟手動改親和性有什麼不同？

    候選涵蓋整顆實體核心的完整邏輯處理器集合（含 SMT sibling），套用前經裝置與核心指紋驗證，寫入遮罩後回讀確認，並保留隨時可用的完整還原。

    滑鼠驅動跟 anti-cheat 相容嗎？

    內建 Raw Accel 官方已簽署驅動（MIT），社群實績包括 FaceIT 與 VAC；但個別 anti-cheat 政策可能改變，PaceDock 不對任何遊戲的相容性作保證，請自行評估。驅動安裝與解除需要重新開機。

    這是開源專案嗎？

    此公開庫只提供發行檔、產品介紹與網站；桌面應用原始碼未公開，公開下載不代表開源授權。GPU 基準測試內建 PresentMon（Intel）與 liblava workload（皆 MIT）。
