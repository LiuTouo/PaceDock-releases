    Before you start

    FAQ

    How do I install it? What rights does it need?

    Windows 11 x64, WebView2, and administrator rights (GPU policy operations). The installer walks you through; the portable build runs after extraction. Binaries are unsigned—an expected SmartScreen warning can be cross-checked against the SHA256 checksum files.

    Can it harm my GPU or system?

    PaceDock does not overclock and never touches frequencies, voltages, or fans; it only adjusts GPU interrupt affinity. Apply and restore restart the display device, so the screen may blink briefly; a complete policy snapshot is always saved first.

    Does a good ranking guarantee faster games?

    No. Rankings reflect this synthetic load only; the "close" label is a display heuristic, not an FPS gain or statistical significance. Judge the final result by your actual games.

    How is this different from setting affinity by hand?

    Candidates cover the full logical-processor set of each physical core (SMT siblings included), applies are validated against device and core fingerprints, masks are read back after writing, and a complete restore is always one click away.

    Is the mouse driver anti-cheat compatible?

    The bundled Raw Accel driver is the officially signed build (MIT) with community history including FaceIT and VAC; individual anti-cheat policies may change, and PaceDock guarantees compatibility with no game—evaluate the risk yourself. Driver install and removal require a reboot.

    Is this an open-source project?

    This public repository provides releases, product information, and the website only; the desktop application's source is not public, and a public download is not an open-source license. GPU benchmarking bundles PresentMon (Intel) and the liblava workload (both MIT).
